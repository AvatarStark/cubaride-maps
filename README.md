# CubaRide offline map packs (test hosting)

Files served to the CubaRide apps by the in-app map pack manager
(CR_MAPS_BASE_URL). Each file is verified on the phone with the SHA-256
listed in manifest.json.

Map data (c) OpenStreetMap contributors, Open Database License (ODbL):
https://www.openstreetmap.org/copyright. Fonts and sprites: see
common/LICENSE-basemaps-assets.md.

Temporary test hosting; production packs will move to CubaRide-owned storage.
